# Miloop Social App

This is a Flutter mobile app mock inspired by the provided reference design: a social/entertainment app with profile cards, room banners, leaderboard blocks, and a gold/gilded theme.

## Features

- Beautiful gold theme and rounded glass cards
- Search bar and category tabs
- Featured room cards
- User profile cards with live counts
- Leaderboard-style monetization cards
- Responsive mobile UI for Android and iOS

## Run the app

1. Install Flutter:
   https://flutter.dev/docs/get-started/install
2. Run:

```bash
flutter pub get
flutter run
```

## Project structure

- `lib/main.dart` — complete application UI

## Notes

This is a front-end UI mockup based on the provided screenshot, not a full backend or real streaming system.
